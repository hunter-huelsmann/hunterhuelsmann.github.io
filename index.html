Skills used: C++, CMake, Visual Studio, 3D Math, Collision Detection, Collision Resolution, Physics Math, ENTT System

Contributors: Hunter Huelsmann, Kinkayde Mortell, Christian Nelson, Dominic Thompson

Don't Get Iced

Don't Get Iced is a santa themed horror game where the player needs to turn on generators to melt the ice blocking the escape route of a maze. This game was made for the Winter Game Jam - 2025 as a solo project.

Skills used: C#, Unity, Level Design, Asset Importing, Audio, Models, Textures, UI

Long Shot

Long Shot was the first VR project I created and released with Unity. It interacts with SteamVR. It was published Oct. 3rd, 2021. I learned the dos and don'ts of making a VR game. This project started my passion for developing games in the simulation and extended reality space.
