Long Shot

Long Shot was the first VR project I created and released with Unity. It interacts with SteamVR. It was published Oct. 3rd, 2021. I learned the dos and don'ts of making a VR game. This project started my passion for developing games in the simulation and extended reality space.

The Tower Of Heck

The Tower Of Heck is a 3D platformer that focuses on the difficulty of each level. This is the first project I developed and released publicly with Unity. I gained my first experience with the game development workflow as a solo developer. I worked with a lot of physics math and design whith this project. It was a great first step in my journey.

2D Kinematics Calculator

This project was created for the Emerging Technologies scholarship at Full Sail University for the Game Development Bachlor's degree. It was made using the kinematics projectile motion subject I had just learned in high school. The user will run the run.bat file to open console. Then they will follow the prompts to enter the values they have. Once all of the values are entered, the calculator will give the missing values back to the user.
